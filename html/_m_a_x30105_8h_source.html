11/***************************************************
12 This is a library written for the Maxim MAX30105 Optical Smoke Detector
13 It should also work with the MAX30102. However, the MAX30102 does not have a Green LED.
14
15 These sensors use I2C to communicate, as well as a single (optional)
16 interrupt line that is not currently supported in this driver.
