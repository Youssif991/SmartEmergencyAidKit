Detailed Description

Heart rate detection using FFT (Fast Fourier Transform) algorithm.

Author
Youssef Mohammed, Youssef Hisham, Mahmoud Abdeldayem
Date
2026-05-06
Version
3.0

Collects IR samples into a sliding circular buffer and applies a Cooley-Tukey radix-2 FFT to find the dominant frequency in the heart-rate band (HR_MIN_BPM - HR_MAX_BPM). Parabolic interpolation refines the peak estimate to sub-bin accuracy.

v3.0 additions: • Bandpass IIR filter (0.5–4 Hz) applied per-sample before the FFT buffer to strip DC drift and high-frequency noise. • SNR quality gate — result is discarded when peak/noise < threshold. • Exponential Moving Average (EMA) on the BPM output to prevent erratic display jumps between updates. • FFT window doubled to 512 samples, halving frequency resolution (≈11.7 BPM/bin) and improving parabolic interpolation accuracy.

The public API (beatAvg / bpm / fingerPresent / irValue) is unchanged so no other files need modification.
